CCS QUEST — WEB TEST VERSION
================================

HOW TO RUN IN VS CODE
1. Extract CCS_Quest_Web.zip.
2. Open the extracted CCS_Quest_Web folder in Visual Studio Code.
3. Open index.html.
4. Recommended: install the "Live Server" extension in VS Code.
5. Right-click index.html and choose "Open with Live Server".
   (You can also double-click index.html to open it directly in a browser.)

CONTROLS
- Click/tap the answer buttons.
- Daily Quest: 7 questions, 25 seconds each.
- Themed Packs: choose a CCS subject.
- Unlimited Mode: a longer shuffled question run.
- Archive and leaderboard use this browser's local storage.

NOTES
- This is a front-end prototype. Scores are saved only in the current browser/device.
- The leaderboard is local, not online or multiplayer.
- Sound effects are generated by the browser using Web Audio (button clicks, game start, correct/wrong answers, timeout, and quest completion). No separate audio files are needed.
- Browsers may require one click/tap before audio can play. Use the 🔊 button to turn sound effects on or off.
- Internet is only needed to load the optional Google Fonts. The game still works without them.
- Includes 530 generated question entries across six CCS subject categories.
- Each Daily Quest randomly selects 7 questions; themed packs randomly select from that subject.
- Unlimited Mode randomly selects a 30-question run.
- The question bank is in question-bank.js. Each entry includes its category, choices, correct answer, and explanation.
- To add/edit questions, edit the window.CCS_QUESTIONS array in question-bank.js.
